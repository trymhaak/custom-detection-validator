# Custom Detection Validator v1.0.0 — release notes

Released 2026-11-21.

Custom Detection Validator pre-validates KQL queries for Microsoft Defender XDR
custom detection rules before they are deployed. It reports missing required
columns, NRT (Continuous) eligibility problems and unavailable response
actions, so detection engineers can fix a query before choosing "Create rule".

## Highlights

- **30 validation rules in six categories:** Table (TBL001–003), Required
  Columns (RC001–007), Non-Supported Columns (NSC001–003), NRT Eligibility
  (NRT001–007), Response Actions (ACT001–005) and Best Practices (BP001–005).
- **Table coverage:** 61 Defender XDR tables, 20 NRT-capable XDR tables,
  19 NRT-capable Microsoft Sentinel tables, known Sentinel tables and custom
  `_CL` tables.
- **Table-aware response actions:** only the actions relevant to the table's
  product (12 product categories) are shown, together with the least-privileged
  RBAC and Entra role and product-specific column hints.
- **Three ways to run it:**
  - in the browser at <https://trymhaak.github.io/custom-detection-validator/>,
    where all validation runs locally in JavaScript;
  - as a CLI (`cdv`) with terminal or JSON output and exit codes for scripting;
  - as a local web UI (`cdv --web`) bound to `127.0.0.1`.
- **No runtime dependencies:** Python 3.9+ standard library only.

## Installation

```bash
pip install .
cdv -q "DeviceProcessEvents | where FileName == 'cmd.exe' | project Timestamp, DeviceId, ReportId"
```
